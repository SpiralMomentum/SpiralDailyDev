## 2.5 성격 이론 기반 결과 (2026-11-19, 사용자 지시)

사용자 지시: "결과 코멘트가 사람이 입력한 답변을 보고 사람의 성격을 대표할 수 있는 성격 테스트 가치가 되어야 한다", "하나의 이론만 쓰는 게 아니라 변경되면서 사용되면 좋겠다. 빅파이브, MBTI, 그 외 이론들", "보석이면 당신은 무슨 무슨 보석처럼 보이네요, 무슨 무슨 보석 같아요", "빅 5 이런 거는 사용자한테 노출되면 안 돼", "왜 XX이다에 대한 설명이 더 길어야 해. 각 테마에 맞게 명언 같은 거, 소설에서 자주 나오는".

이전 구현이 성격 테스트처럼 보이지 않던 원인 (수정 전 상태):
- 프롬프트 금지 패턴에 `당신은.*사람` 이 있어 "넌 ~한 사람이다" 같은 성격 단정 문장을 막고 있었다.
- 선택지 72개는 채널 내 원형 번호(0~3)에만 연결되고, 원형에는 칭호 1개와 분위기 대사 2줄만 있었다. 답이 어떤 성향을 뜻하는지 모델이 참고할 자료가 없었다.
- 원형 번호의 의미가 채널마다 달라(무협 0 = 직진, 동물 0 = 협동) 누적 발현이 채널을 넘는 성향 패턴을 말할 근거가 없었다.

## 2.6 장르 문체 조사와 명언 (2026-11-19, 사용자 지시)

사용자 지시: "명언이라도 평시에 자주 사용되는 표현이면 저작권 문제 없지 않나? 각 스타일에 맞는 커뮤니티 찾아서 문체 어투 학습해서 템플릿 만들어서 넣는 방식으로 접근".

## 11. 알려진 제약

- `flutter_gemma` 는 pub.dev 에서 중단(discontinued) 표시된 패키지이고 후속은 `flutter_edge_ai`. 저장소 Flutter 를 3.44 이상으로 올리면 옮겨야 한다.
- 빌드할 때 flutter_gemma 가 GitHub 릴리스에서 LiteRT-LM 네이티브 라이브러리를 내려받는다 (체크섬 검증 로그 확인). 오프라인 빌드 환경에서는 캐시(`~/Library/Caches/flutter_gemma/native`)가 필요하다.
- `flutter drive` 는 실행마다 앱을 지우고 다시 설치해 모델(2.4GB)도 지워진다. 통합 테스트마다 모델을 다시 받는다 (로컬 미러 기준 약 4.5분).
- 모델 다운로드 중 앱이 종료되면 처음부터 다시 받는다 (Hugging Face CDN 이 이어받기를 지원하지 않는다는 flutter_gemma 문서 기준).
