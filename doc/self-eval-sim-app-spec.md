# 자기평가 시뮬레이션 앱 기능 개발서

작성일: 2026-11-18 / 작성: GyuBin

## 1. 확정 사항 (사용자 발언 기준)

아래는 사용자가 직접 말한 내용만 옮긴 것이며, 해석이나 보완을 붙이지 않았다.

| 항목 | 확정 내용 |
| --- | --- |
| 앱 성격 | 온디바이스 AI 모델을 포함해서, 일종의 다양한 시뮬레이션을 제공하는 앱 |
| 타겟 | 라이트하게, 사용자들이 자신을 평가받고 싶어하는 욕망을 살리는 사용자 |
| 자기평가 채널 | 무협, 판타지, 동물, 보석 등 다양한 채널 ("등"으로 끝났으므로 전체 목록은 미확정) |
| 입력 방식 | 사용자에게 선택지를 받음 (일종의 성격 테스트처럼) |
| 입력 방식의 목적 | 결과에 대해 상대적으로 더 공감할 수 있게 하기 위함 |
| 핵심 컨셉 | 개별 시행이 아니라 누적 시행 |
| 누적의 반영 방식 | 매번 누적 결과로 업데이트된 결과를 보여주는 방식이 아님 |
| 평소 시행 | 대다수의 시도는 개별 시행으로, 평소와 크게 다르지 않음 |
| 누적 발현 | 뜬금없이 누적된 컨텍스트를 보고 발발하는 느낌 |

### 추가 확정 (2026-11-18 사용자 답변)

- 온디바이스 AI 역할: 결과 문구 생성, 선택지 자체 생성, 누적 맥락 해석 및 발현 판단 - 세 가지 모두 고려 중
- 온디바이스 모델 포함 방식: 처음 실행 때 내려받음. 모델 단독 용량 상한을 따로 둠
- 답변 포맷: 사용자가 제공. 예시문 중심이며 금지 패턴이 더 많을 예정. 제공 시점은 채널이 정해진 뒤. 어투, 자주 쓰는 단어, 어순에서 AI 티가 나면 안 됨
- 플랫폼: iOS와 Android 둘 다
- 지원 기기: 최신 플래그십 위주
- 지원 언어: 한국어, 영어, 일본어, 중국어
- 오프라인: 필수. 오프라인에서는 광고 없이 동작. 최초 모델 다운로드 전까지는 사용 불가
- 수익 모델: 광고, 형태는 보상형 광고. 사용자 답변 후 결과가 만들어지는 대기 시간에 병렬로 제안하고, 광고를 보면 대기 시간을 벌어 주는 구조. 노출 빈도는 누적 발현 시에만
- 광고 보상: 결과 장면 확장 (추가 장면과 추가 서술 둘 다)
- 공유: 이미지 공유. 공유물에는 결과 장면 이미지, 미연시처럼 화면 및 짧은 애니메이션, 대사창이 지나가는 느낌을 담음. 파일 형태는 움직이는 이미지(GIF 등)
- 채널: 이미 말한 4개보다 더 많기를 원함 (최종 목록은 사용자가 고름)
- 선택지 구성: 채널별로 다름
- 결과 형태: 채널 컨셉에 맞춘 이미지와 서술 (예: 보석은 보석상에서 설명받는 구도, 무협은 산속/전쟁터에서 강한 상대나 대중이 평가하는 장면, 판타지는 궁전의 공주 등)
- 이미지: 사전 제작 에셋, AI 도구로 제작
- 누적 범위: 전체 통합 누적 / 보관 형태: 선택 원본 로그 / 보관 기간: 무제한, 전체 삭제 가능
- 저장 위치: 기기 안에만 저장, 기기 변경 및 앱 삭제 시는 OS 기본 백업 활용
- 발현 조건: 무작위 + 천장. 시행마다 확률 상승, 발현 시 초기화, 시작 0%, 시행당 증가폭은 10%p 이하 랜덤
- 발현 형태: 기존 결과에 섞임, 별도 연출 둘 다 가능하며 무작위로 선택
- 발현 기록: 발현도 다시 누적에 사용. 이전 발현을 새 발현의 재료로 쓰고, 똑같은 누적은 없는 것처럼 보여야 함 (사용자 컨셉)
- 재료 규칙: 과거 누적 발현의 비중을 개별 시행보다 많이 가져가되 과거 발현 6 : 개별 시행 4 (시장 반응을 보며 조정)

### 의사결정 원칙 (사용자 지정)

- 추측, 가정, 임의 판단 금지
- 의사결정은 사용자가 함
- 아이디어 제공은 허용

## 2. 기능 영역 구조

확정 사항에서 바로 드러나는 기능 영역은 6개이며, 각 영역의 세부 사양은 아직 비어 있다. 빈칸은 3절에서 사용자가 채울 결정 항목이다.

| # | 기능 영역 | 근거 (사용자 발언) | 세부 사양 상태 |
| --- | --- | --- | --- |
| A | 온디바이스 AI 모델 | "온디바이스 ai 모델을 포함" | 역할 미정 (D1) |
| B | 자기평가 채널 | "무협이라던지 판타지라던지 동물 보석 등 다양한 자기평가 채널" | 채널 목록/구조 미정 (D2) |
| C | 선택지 입력 | "사용자에게 선택지(일종의 성격 테스트처럼)를 받아서" | 문항 구성/분량 미정 (D3) |
| D | 개별 시행 결과 | "대다수의 시도는 개별 시행으로 평소와 다를 게 크게 없음" | 결과 형태 미정 (D4) |
| E | 누적 컨텍스트 보관 | "개별 시행이 아니라 누적시행이 컨셉" | 보관 범위/방식 미정 (D5) |
| F | 누적 발현 | "뜬금없이 누적된 컨텍스트를 보고 발발하는 느낌" | 발현 조건/빈도/형태 미정 (D6) |

## 3. 결정 필요 항목

기능 명세를 쓰려면 아래 10개를 사용자가 정해야 한다. 옵션 열은 아이디어 참고용이며, 추천이나 우선순위가 아니다. 결정 열이 비어 있으면 미결정이다.

| ID | 결정할 것 | 아이디어 옵션 (채택 미정) | 결정 |
| --- | --- | --- | --- |
| D1 | 온디바이스 AI가 맡을 역할 | 결과 문구 생성 / 선택지 자체 생성 / 누적 맥락 해석 및 발현 판단 / 위 항목의 조합 / 그 외 | 세 가지 모두 고려 중 |
| D2 | 채널 목록과 채널 간 관계 | 초기 채널 수 확정 / 채널별 독립 누적 vs 채널 전체 통합 누적 / 신규 채널 추가 방식 | 전체 통합 누적 |
| D3 | 선택지 입력 방식 | 문항 수 / 문항 고정 vs 매번 변화 / 문항당 선택지 수 / 1회 소요 시간 | |
| D4 | 개별 시행 결과의 형태 | 칭호/등급 / 짧은 서술 / 카드 이미지 / 수치 스탯 / 조합 | |
| D5 | 누적 데이터 보관 | 저장 위치(기기 내 / 서버) / 저장 형태(선택 원본 로그 / 요약 프로필) / 보관 기간 / 사용자 삭제 기능 | 저장 위치는 기기 안만 (나머지 미정) |
| D6 | 누적 발현 방식 | 조건(시행 횟수 도달 / 특정 패턴 감지 / 무작위 / 시간 경과) / 빈도 / 형태(기존 결과 문구에 섞임 / 별도 연출) / 발현 후 처리 | 조건은 무작위 + 천장 (나머지 미정) |
| D7 | 플랫폼 | iOS / Android / 둘 다 / 크로스플랫폼 프레임워크 사용 여부 | |
| D8 | 온디바이스 모델 선정 기준 | 모델 크기 상한 / 지원 기기 하한 / 오프라인 동작 필수 여부 | |
| D9 | 결과 공유 기능 | 없음 / 이미지 공유 / 링크 공유 | |
| D10 | 수익 모델 | 무료 / 광고 / 구독 / 채널 단위 판매 / 미정 | |

참고: 위 표의 D3, D4, D7, D8, D9, D10 결정 열은 비어 있으나, 1절 "추가 확정"에 해당 항목의 사용자 답변이 기록되어 있다 (D3 선택지 구성은 채널별로 다름, D4 결과 형태, D7 플랫폼, D8 지원 기기/오프라인/용량 방식, D9 이미지 공유, D10 광고). 표의 결정 열은 문서 작성 시점의 표 기입 상태를 그대로 옮긴 것이다.

### 답변에서 새로 생긴 미결정 항목

- 최종 채널 목록 (아이디어 목록에서 사용자가 선택)
- 채널별 문항 수, 선택지 수
- 모델 단독 용량 상한 수치 (아이디어 보고 사용자가 결정)

## 4. 아이디어 풀 (채택 여부 미정)

아래는 제안일 뿐 확정 사항이 아니다. 채택할 것만 골라 3절 결정에 반영한다.

### 채널 아이디어 (D2 관련)

- 무협: 문파, 경지, 병기 기반 평가
- 판타지: 직업, 종족, 속성 기반 평가
- 동물: 닮은 동물 판정
- 보석: 원석, 광택, 투명도 기반 평가
- 그 외 후보: 별자리/행성, 날씨, 식물/나무, 악기, 몬스터

### 누적 발현 아이디어 (D6 관련)

- **숨은 카운터**: 사용자에게 보이지 않는 누적 지표가 임계값에 도달하면 발현
- **과거 선택 회상**: 오래전 특정 선택을 불러와 현재 선택과 대조
- **모순 포착**: 같은 질문에 시기별로 다른 선택을 했을 때 그 변화를 언급
- **채널 간 교차 발현**: 한 채널의 누적이 다른 채널 결과에 스며듦 (D2에서 통합 누적을 고를 경우에만 성립)
- **발현 기록 모음**: 발현된 순간만 따로 모아 보는 컬렉션
- **기기 내 해석**: 누적 기록을 온디바이스 모델이 기기 안에서 해석 (D1, D5 결정에 의존)
