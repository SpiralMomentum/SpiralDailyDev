1. 개인정보처리방침 개요

Spiral Dev(이하 "개발자")는 사용자의 개인정보를 중요시하며, 관련 법령을 준수합니다. 본 개인정보처리방침은 Spiral Dev가 제공하는 아래 애플리케이션(이하 "앱")에 적용됩니다.

  • Adage Spark (격언 관리)
  • Daily Memo (일일 메모)
  • Film Archive (영화 아카이브)
  • Luck Insight (운세)
  • World Field Guide (세계 특산품 가이드)
  • World of Beast (괴물 도감)

2. 수집하는 개인정보 항목

개발자는 최소한의 정보만을 수집하며, 수집 항목은 다음과 같습니다.

항목 수집 목적 대상 앱
앱 사용 데이터 (화면 조회, 기능 사용 빈도) 앱 품질 개선 및 사용자 경험 분석 전체 앱
앱 충돌 로그 오류 추적 및 안정성 향상 전체 앱
Firebase 서비스 관련 데이터 클라우드 동기화 및 분석 Daily Memo

개발자는 사용자의 이름, 이메일 주소, 전화번호, 위치 정보 등 직접적인 개인 식별 정보를 별도로 수집하지 않습니다.

3. 데이터 저장 방식

사용자가 앱 내에서 생성하는 데이터(메모, 설정 등)는 주로 사용자의 로컬 기기에 저장됩니다. Daily Memo 앱의 경우 Firebase 서비스를 활용하여 일부 데이터가 클라우드에 저장될 수 있습니다.

4. 개인정보의 제3자 제공

개발자는 사용자의 개인정보를 제3자에게 제공하지 않습니다. 다만, 앱 사용 분석을 위해 Firebase Analytics를 사용하며, 이 과정에서 익명화된 사용 데이터가 Google 서버에 전송될 수 있습니다. 해당 데이터는 개별 사용자를 식별할 수 없는 형태로 처리됩니다.

Firebase의 데이터 처리에 관한 자세한 내용은 Firebase 개인정보처리방침을 참조하시기 바랍니다.

5. 개인정보의 보유 및 파기

로컬 기기에 저장된 데이터는 앱 삭제 시 함께 제거됩니다. Firebase를 통해 저장된 데이터는 사용자 요청 시 삭제 처리됩니다. 삭제를 원하시는 경우 아래 연락처로 요청해 주시기 바랍니다.

6. 아동의 개인정보 보호

개발자는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만약 이에 해당하는 정보가 수집된 사실을 인지하게 될 경우, 즉시 해당 정보를 삭제하겠습니다.

7. 개인정보처리방침의 변경

본 개인정보처리방침은 관련 법령 변경 또는 서비스 변경에 따라 수정될 수 있습니다. 변경 사항이 있을 경우, 본 페이지를 통해 공지합니다.
